Sigpress

Monad testnet · chain — optimistic aggregation · STARK next

Post-quantum signatures without losing Monad's block space. Switch to the PQ scheme in Monad's own account-auth draft and a block's capacity drops ~90%. Sigpress puts one 32-byte root on chain per batch instead of every signature, so quantum-safe transactions cost almost nothing in block space.

Honest limits. This is optimistic aggregation, not a validity proof: there is a challenge window and the aggregator serves signature data. It is still post-quantum end to end (real WOTS signatures, checked on chain in a challenge) and lives on Monad testnet. The one-hash-based-STARK-over-N-signatures version is the product (kill tests K3–K6).
